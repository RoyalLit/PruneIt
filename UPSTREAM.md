PruneIt does **not** track upstream automatically. To review upstream changes:

```sh
git remote add upstream https://github.com/jithin-sabu/purge-app
git fetch upstream
git log 7d410de8f0e5facde8c49ba6427e49b53ff3764a..upstream/main --oneline
```

Safety-critical fixes should be reviewed and cherry-picked manually.
